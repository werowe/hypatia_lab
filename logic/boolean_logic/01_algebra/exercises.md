## Switches and tables

**A1.** Explain x + 1 = 1 and x0 = 0 using a switch network. What physical arrangement represents the constant in each case?

**A2.** Draw switch networks for xy + z and x(y + z). Find one input assignment giving different outputs.

**A3.** Make the eight-row table for f = x'y + z. Include a column for x'.

**A4.** Explain why two independent switches cannot be labelled x and x' unless their operation is constrained.  **Constrained** means the switches are linked so they must always be in opposite states: when x is open (0), x' is closed (1), and vice versa.

## Algebra

**A5.** Simplify each expression and name the laws used:

1. xy + xy'
2. x + xy + xz
3. (x + y)(x + y')
4. x + x'y

**A6.** Complement and simplify:

1. xy + z
2. x(y + z')
3. x' + yz

**A7.** Test the claim x + yz = (x + y)z. If false, provide a counterexample.

**A8.** Prove xy + x'z + yz = xy + x'z. Hint: replace yz by yz(x + x') and use absorption. Explain why a term can be removed even if it contains neither 0 nor a repeated literal.
