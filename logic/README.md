# Logic: circuits, Boolean algebra and proofs

[← Back to the electronics course](../README.md)

How does a conducting path become a Boolean expression, and how can changing that expression remove unnecessary hardware? These notes connect powered switch networks to Boolean laws, proofs and circuit design. The later arithmetic unit develops half adders, full adders and a four-bit adder. Arithmetic material is retained for later lessons and videos; it is outside the first two gate-to-algebra videos.

This index covers all 25 Markdown files in `logic/`, including this README, the nested course, homework, teacher notes and diagram gallery. The [reading index](#reading-index) describes the contents in teaching order. The separate [laws, proofs and circuits index](#laws-proofs-and-circuits-index) locates particular identities, worked derivations, truth-table checks and physical explanations.

## Start here

- [Connecting Electric Circuits to Boolean Algebra](boolean_logic/01_algebra/connecting_gates_to_boolean_algebra.md) is the bridge from powered switch networks and conducting paths to notation, proofs and simplification. Begin here if you already know gates.
- [Full Boolean course map](boolean_logic.md) introduces the seven-lesson sequence, notation, practical expectations and book reading.
- [Mathematical Laws and Boolean Algebra](math_boolean_laws.md) connects familiar arithmetic laws to Boolean reasoning; [Boolean Algebra Laws and Proofs](proofs.md) supplies the supporting proofs.
- [Build gates from a 74HC00](../lectures/74hc00.md) connects this material to the surrounding course's NAND-gate lab.

Read `+` as OR, a product such as `xy` as AND, and `x'` as NOT x. Boolean `1 + 1 = 1` describes a true condition; numerical binary addition gives `10`. Repeated contact labels denote the same linked control. Boolean equivalence means equal outputs for all permitted inputs; it does not establish equal current, brightness, delay or transistor count.
