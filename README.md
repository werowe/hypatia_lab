## 🔬 What This Course Is

</div>

<table>
<tr>
<td width="50%" valign="top">

### 🧠 Not a tutorial course

You will not copy code off a screen. You build a circuit,
you break it, you measure it, and you find out **why**
electrons did what they did.

</td>
<td width="50%" valign="top">

### ⚙️ C, not Python

C is the language the hardware actually speaks. Pointers,
memory, and raw bits are not "advanced topics" here —
they are the whole point.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 🔌 Real components

Breadboards, resistors, 2N2222 transistors, 74HC00 NAND
chips, shift registers. Real parts that get warm and
occasionally let out smoke.

</td>
<td width="50%" valign="top">

### 🏆 One big finish

Everything converges on **NANDINO-4** — a working 4-bit CPU
emulator built from nothing but NAND gates.

</td>
</tr>
</table>

<div align="center">

<br>

### 🎯 The NAND Rule

<table>
<tr><td align="center">

**Every logic gate in this course is built from NAND gates.**

AND, OR, NOT, XOR — all of them. One primitive, assembled over and over,
until it becomes a computer. That is the thread that runs from week 1
to the final project.

</td></tr>
</table>

## 🧰 What You Need

</div>

<table>
<tr>
<th align="left" width="30%">Item</th>
<th align="left">Notes</th>
</tr>
<tr>
<td><strong>A computer</strong></td>
<td>Any OS. We compile C from the command line.</td>
</tr>
<tr>
<td><strong>An Arduino Uno</strong></td>
<td>A clone is fine and costs a fraction of the price.</td>
</tr>
<tr>
<td><strong>A breadboard kit</strong></td>
<td>Jumper wires, LEDs, resistors, push buttons.</td>
</tr>
<tr>
<td><strong>2N2222 transistors</strong></td>
<td>For building gates out of raw silicon. Buy a pack of 10.</td>
</tr>
<tr>
<td><strong>74HC00 NAND ICs</strong></td>
<td>Four NAND gates per chip. The heart of the course.</td>
</tr>
<tr>
<td><strong>Curiosity</strong></td>
<td>No prior programming or electronics experience required.</td>
</tr>
</table>
